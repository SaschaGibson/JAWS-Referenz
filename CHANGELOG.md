# Changelog

## Complete Repository - All Commits Merged

This repository represents the complete JAWS Scripting Reference with all historical commits consolidated.

### Content Included

- **Documentation**: Complete JAWS scripting API documentation covering functions, events, and data types
- **Script Files**: Comprehensive collection of scripts for various applications
  - Office Applications (Word, Excel, Outlook, PowerPoint)
  - Web Browsers (Firefox, Chrome, Edge, Internet Explorer)
  - Development Tools (Visual Studio, Eclipse)
  - Multimedia (Winamp, iTunes, Spotify, YouTube)
  - Accessibility Tools (ZoomText)
  - System Utilities

- **Settings**: Configuration files and user settings
- **Examples**: HTML demo files and code examples
- **Learning Resources**: Tutorials and walkthroughs for JAWS scripting

### File Types
- `.md` - Markdown documentation files
- `.jsb`, `.jss`, `.jsm`, `.jsh` - JAWS script files
- `.qs`, `.qsm` - Quick Settings files
- `.jcf`, `.jdf`, `.jkm`, `.jsd`, `.jff` - JAWS configuration files
- `.html` - Demo and example files
