# JAWS Scripting Reference

This repository contains a comprehensive reference for JAWS (Job Access With Speech) scripting.

## Overview

JAWS is a screen reader developed by Freedom Scientific that provides access to computer applications for users who are blind or have low vision. This repository includes:

- Complete API documentation for JAWS scripting functions
- Script files for numerous applications
- Configuration and settings files
- Examples and learning resources

## Contents

### Documentation Files (`.md`)
- API Tools
- Functions (events, keyboard, mouse, navigation, etc.)
- Data Types (arrays, collections, dictionaries, etc.)
- Braille support
- Speech and verbosity controls
- Virtual cursor features

### Script Files
Scripts are provided for many popular applications including:
- Microsoft Office (Word, Excel, Outlook, PowerPoint)
- Web Browsers (Firefox, Chrome, Edge)
- Development Tools (Visual Studio, Eclipse)
- Media Players (Winamp, iTunes, Spotify)
- PDF Readers (Adobe Acrobat)
- And many more...

### Settings
Example configuration files showing JAWS customizations for various applications and use cases.

## File Extensions

- `.jsb` - JAWS Script Binary (compiled scripts)
- `.jss` - JAWS Script Source
- `.jsm` - JAWS Script Message
- `.jsh` - JAWS Script Header
- `.qs` / `.qsm` - Quick Settings
- `.jcf` / `.jdf` / `.jkm` / `.jsd` - Configuration files
